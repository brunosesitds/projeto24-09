# Evidências de Entrega

- Código-fonte completo: arquivos `main.py`, `interface.py`, `dados.py`, `validacoes.py`.
- Banco SQLite de exemplo: `projeto_tkinter.db` (gerado ao executar).
- README com instruções de execução: `README.md`.
- Script de testes: `tests/smoke_test.py` (executar para verificar CRUD).
- Proposta e respostas de pesquisa: `proposta_projeto.md` e `respostas_pesquisa.md`.

Passos para demonstrar (5-7 minutos):
1. Executar `python main.py` e mostrar cadastro, edição e exclusão.
2. Mostrar pesquisa por texto e persistência fechando e reabrindo o app.
3. Mostrar `tests/smoke_test.py` rodando para demonstrar CRUD automático.
